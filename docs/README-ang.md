# Sample Angular - Weather Forecast App

This Angular TypeScript application demonstrates how to consume the Weather Forecast API with Windows Authentication.

## Features

- **Angular 19** with standalone components
- **TypeScript** for type-safe development
- **HttpClient** for API communication
- **RxJS** for reactive programming
- **WeatherForecast model** matching the C# API model
- **Windows Authentication** support via credentials

## Prerequisites

- Node.js (v18 or higher)
- Angular CLI (`npm install -g @angular/cli`)
- Running Weather Forecast API at `https://localhost:7654`
